# Hotel Cancellation Analysis

> Work in progress

**Question:** which hotel bookings are likely to be cancelled, how much revenue is at stake, and what can a hotel do about it?

**Data:** Hotel Booking Demand (Antonio, Almeida & Nunes, 2019): bookings of a resort hotel and a city hotel in Portugal, arrivals from July 2015 to August 2017.

**Tools:** Python (pandas, scikit-learn, matplotlib) · Tableau · Jupyter
